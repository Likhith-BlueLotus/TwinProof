How it works

Four steps,one verdict

  • 01Film itTen seconds of phone video with a printed ArUco marker in frame. No lab, no sensors.
  • 02Track itSAM 3.1 follows the object every frame; the marker turns pixels into metres.
  • 03Twin itA MuJoCo twin fitted by CMA-ES, with a posterior that says how sure it is.
  • 04Prove itGates G7 to G5 admit or refuse every claim, naming the number that decided.

Filmed ona phone,not a lab

Five real rigs, three pendulums and two ramps, each a short take with a printed marker. The pipeline measured them, and caught a wrong ramp angle on its own.

Your own take

Film yourown take

  1. Print the marker at 100% and measure its side with a ruler.
  2. Film about 10 seconds with the phone on a stand, the marker and the object both in frame.
  3. Run the pipeline on your take, then open the run in the console:
uv run --env-file .env python -m scripts.run_s1_video take.mp4 --side 0.07 --noun ruler
uv run --env-file .env python -m scripts.run_agent_s1 logs/runs/take_s1.npz
